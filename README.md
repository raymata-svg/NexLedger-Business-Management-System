# NexLedger — Business Management System

A full-stack business management system built with Flask and SQLAlchemy for managing business finances, payroll, and financial performance.

## 📊 Overview

NexLedger provides a centralized dashboard for tracking business revenue, expenses, employee payroll, and overall financial performance.

## ✨ Features

- 📈 Revenue management
- 💰 Expense tracking and categorization
- 👨‍💼 Employee payroll management
- 📊 Financial reporting
- 📉 Revenue vs. expense analytics
- 🔎 Search and filtering
- ✏️ Create, edit, and delete records
- 🔐 Login system
- 💾 SQLite database
- 📱 Responsive interface

## 🛠️ Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2
